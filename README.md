## 📖 About This Repository

This repository hosts supplemental learning materials and demonstration scripts used in instructor-led AWS Technical Essentials training:

* **[aws_technical_essentials_questions.pdf](aws_technical_essentials_questions.pdf)** — Review and knowledge-check questions covering core AWS compute, networking, storage, and database concepts.
* **[aws_technical_essentials_answers.pdf](aws_technical_essentials_answers.pdf)** — Detailed answer key and rationales for course review questions.
* **[AWSTechFest_QA.pdf](AWSTechFest_QA.pdf)** — Extended Q&A notes and architectural discussions.

### 🧪 Hands-On Lab Scripts & Setup Files

* **`lab1_create_IAM_user.txt`** — IAM user and policy assignment configuration.
* **`lab2_ec2_webserver.txt` & `lab2_ec2_webserver_sudo.txt`** — Web server bootstrap script for Amazon EC2 instances.
* **`lab5_dynamodb.txt`** — Amazon DynamoDB table creation and sample queries.
* **`s3_bucket_policy.txt`** — Secure Amazon S3 bucket policy template.
* **`stress_test.txt`** — CPU/workload stress testing script for Auto Scaling demonstrations.
* **`userdata_linux.txt`** — EC2 User Data script for automated web server deployment.
* **`AWSESS_L01.zip` – `AWSESS_L05.zip`** — Lab archive bundles for Modules 1 through 5.
